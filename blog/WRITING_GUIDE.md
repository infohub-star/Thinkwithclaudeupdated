## Audience
Working professionals, team leads, founders, doctors, coaches and HR/L&D heads in India.
Non-technical. Busy. Want practical results, not theory.

## Style
- Plain, direct English. Short paragraphs (2-4 sentences). No jargon without a one-line explanation.
- Open with the reader's problem in 2-3 sentences, then get practical fast.
- Include at least one copy-paste prompt in a code block, written in the RACT style
  (Role, Ask, Context, Tone).
- Use real-feeling Indian work examples (e.g. a Bengaluru HR manager, a Pune clinic).
- Don't invent statistics, studies, quotes, client stories or product features.
  If a fact is time-sensitive (tool features, pricing, releases), check it with a web search first.
- No hype words: "game-changer", "revolutionize", "unlock", "delve", "in today's fast-paced world".
- End with a short "Try this today" section with 2-3 concrete steps.

## Format and SEO
- 900-1,400 words. H2 sections (`##`), H3 where useful. No H1 in the body (the title is the H1).
- Title under 65 characters, includes the main keyword naturally.
- Description 140-155 characters, a clear benefit.
- Slug: 3-6 lowercase words with hyphens.
- Add an "## FAQs" section with 3 short Q&As (helps AI search / AEO).
